# Expert Financeiro

Assistente financeiro em formato de chat, desenvolvido para consultar
contas, saldos e transações fictícias do Plaid Sandbox.

## Objetivo

Apresentar informações financeiras em linguagem simples e permitir
consultas de saldo, transações e gastos por categoria.

## Integrações previstas

- Plaid Sandbox: dados financeiros fictícios.
- Pluggy: documentação sobre integração financeira brasileira.
- MCP: conexão da IA com ferramentas externas.

## Estrutura

- `frontend/`: interface do chat.
- `backend/`: servidor e integrações.

## Status

Configuração inicial. O aplicativo e as integrações ainda não foram implementados.

## Segurança

Este projeto utiliza dados fictícios.
Credenciais devem permanecer em arquivos locais ignorados pelo Git.
